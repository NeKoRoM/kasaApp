# Апаратне підключення, інтерфейси та розпайка: Exellio & Datecs (Hardware Reference)

> **Призначення:** Інженерна документація з фізичних інтерфейсів, розпайки кабелів зв'язку, електричних характеристик та налаштування каналів зв'язку для апаратів **Exellio** та **Datecs**.

---

## 1. Схема розпайки послідовних портів RS-232 (RJ-12 $\rightarrow$ DB-9F)

На більшості моделей Exellio (DP-05, DP-25, FP-700) для RS-232 використовуються модульні гнізда **RJ-12 (6P6C)**.

```
       Вигляд гнізда RJ-12 (каса)           Вигляд гнізда DB-9F (ПК)
               [ 1 2 3 4 5 6 ]                   1   2   3   4   5
                 ||||||                           o   o   o   o   o
                 +----+                             o   o   o   o
                                                   6   7   8   9
```

### 1.1. Стандартний комунікаційний кабель (Каса $\rightarrow$ ПК)

| Пін RJ-12 (Каса) | Назва сигналу | Напрямок | Пін DB-9F (ПК) | Примітки |
| :---: | :---: | :---: | :---: | :--- |
| **1** | `+5V / NC` | Вихід з каси | — | **Увага:** Живлення для зовнішніх сканерів (до 300 мА). До ПК НЕ підключати! |
| **2** | `TXD` | Каса $\rightarrow$ ПК | **Pin 2** (RXD) | Лінія передачі даних з каси |
| **3** | `RXD` | ПК $\rightarrow$ Каса | **Pin 3** (TXD) | Лінія прийому даних касою |
| **4** | `RTS / DTR` | Апаратний контроль | **Pin 4** або **Pin 7** | Опціонально (зазвичай не використовується при 8N1) |
| **5** | `GND` | Земля | **Pin 5** (GND) | Загальний сигнальний нуль |
| **6** | `GND` | Земля | **Pin 5** (GND) | Дублююча земля або NC |

> [!CAUTION]
> **Небезпека пошкодження обладнання:**
> На Pin 1 гнізда RJ-12 подається напруга `+5V` (у касових апаратах) або до `+12V/+24V` (на деяких портах для зовнішніх дисплеїв). Якщо випадково замкнути цей контакт на корпус або сигнальну лінію RS-232 комп'ютера, можна вивести з ладу мікросхему драйвера інтерфейсу MAX232 / MAX3232 на платі каси або материнській платі ПК.

## 2. Інтерфейс підключення грошової скриньки (Cash Drawer Port)

* **Роз'єм:** RJ-11 (6P4C або 6P6C).
* **Електричний сигнал:** Імпульс постійного струму (DC Pulse).
  * Реєстратори серії **FP-700 / FP-2000:** **24V DC, до 1A**.
  * Портативні касові апарати **DP-05 / DP-25:** **6V / 12V DC** (залежно від модифікації живлення).
* **Схема розпайки:**
  * **Pin 1:** Корпус / Екран
  * **Pin 2:** Сигнал активації соленоїда (Open Drawer Pin 1)
  * **Pin 3:** Датчик відкриття (Micro-switch sensor)
  * **Pin 4:** Живлення соленоїда `+24V / +12V`
  * **Pin 5:** Сигнал активації соленоїда 2 (Open Drawer Pin 2)
  * **Pin 6:** Земля датчика (GND)
* **Команда відкриття з ПЗ:** Команда 106 (`0x6A`): `{mSec}\t`, рекомендований імпульс: `50`–`100` мс (наприклад `50\t`).

## 3. Bluetooth модуль (SPP / Serial Port Profile)

* **Модель чіпа:** Bluegiga WT12 / Quectel / Broadcom / Realtek SPP.
* **Профіль:** Bluetooth Classic, **Serial Port Profile (SPP)**.
* **UUID сервісу:** `00001101-0000-1000-8000-00805F9B34FB` (стандартний для віртуального послідовного порту).
* **Параметри зв'язку віртуального UART:**
  * Baud rate: **115200 bps**
  * Data bits: **8**
  * Parity: **None**
  * Stop bits: **1**
  * Flow control: **None**
* **Заводський PIN-код для спарювання:** **`0000`** або **`1234`**.
* **Команди конфігурації Bluetooth (Command 255 / 0xFF):**
  * `BthEnable` $\rightarrow$ `1` (увімкнено) / `0` (вимкнено)
  * `BthDiscoverability` $\rightarrow$ `1` (видимий для інших пристроїв)
  * `BthPairing` $\rightarrow$ `0` (без шифрування), `1` (запам'ятати зв'язку), `2` (скинути пару)
  * `BthPinCode` $\rightarrow$ встановлення пароля спарювання (до 16 цифр)
  * `BthName` $\rightarrow$ мережеве ім'я пристрою (наприклад, `DP-25-001234`)

## 4. USB-інтерфейс (Virtual COM Port)

* **Типи роз'ємів:**
  * DP-05 / DP-15: **Micro-USB**
  * DP-25 / DP-35 / DP-150: **Mini-USB** або **USB Type-B**
  * FP-700 / FP-2000: **USB Type-B**
* **Протокол USB:** CDC-ACM (Communications Device Class - Abstract Control Model).
* **Ідентифікатори пристрою (VID / PID):**
  * Datecs USB CDC: `VID_0483` (STMicroelectronics) / `PID_5740` або `VID_10C4` (Silicon Labs CP210x).
  * У старих версіях використовувався чіп Prolific `PL-2303` (`VID_067B` / `PID_2303`) або FTDI FT232R (`VID_0403` / `PID_6001`).
* **Робота під ОС:**
  * **Android:** Не потребує root-прав. Підключається через Android USB Host API (`UsbManager` / `UsbDeviceConnection` з endpoints IN/OUT, bulk transfer).
  * **Linux / macOS:** Розпізнається як `/dev/ttyACM0` або `/dev/tty.usbmodem*`.
  * **Windows:** Потребує драйвера `Datecs USB Virtual COM Driver`.

## 5. Мережевий Ethernet (LAN) та Wi-Fi інтерфейси

* **Мережевий контролер:** WIZnet W5500 або вбудований у процесор MAC/PHY.
* **Роз'єм:** RJ-45 (10/100 Mbps Base-T).
* **Режими адресації:** DHCP або статичний IP (`LAN_IP`, `LAN_NetMask`, `LAN_Gateway`).
* **Порт фіскального зв'язку (Command Socket):** **`4999`**
  * До сокета надсилаються абсолютно ті самі байти протоколу Datecs, що й у послідовний порт або по Bluetooth (`<0x01>` ... `<0x05>` + BCC + `<0x03>`).
  * Пристрій підтримує до 2 одночасних TCP-з'єднань.

## 6. Механізми термічного друку (Thermal Printers)

* **Моделі принтерів:**
  * Exellio DP-05 / DP-25: Seiko Instruments **LTP01-245** (57 мм).
  * Exellio FP-700: Seiko Instruments **CAPD245 / CAPD345** з автообрізчиком.
* **Ширина паперу:** 57 мм (ефективна ширина друку 48 мм, 384 точки) або 80 мм (576 точок).
* **Вбудовані датчики:**
  * `PESENS` (Paper End Sensor) — оптичний рефлекторний датчик наявності паперу.
  * `NESENS` (Near Paper End Sensor) — датчик закінчення рулону (попередження).
  * `HDSENS` (Head / Cover Open Sensor) — мікроперемикач відкритої кришки касети.
  * Терморезистор голівки — захист від термічного перегріву (при досягненні 65°C блокує друк до охолодження).
