# Словник кодів помилок Datecs v2 / Exellio (Error Codes Dictionary)

У протоколі Datecs v2 відповідь на команду у першому полі даних повертає ціле число `ErrorCode`.
* Якщо `ErrorCode == 0` — операцію виконано успішно.
* Якщо `ErrorCode < 0` — код помилки. Нижче наведено повну класифікацію кодів.

---

## 1. Загальні помилки зв'язку та пристрою (-100000 .. -100009)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-100001** | `ERR_IO` | Помилка вводу-виводу (неможливо прочитати або записати дані в порт). |
| **-100002** | `ERR_CHECKSUM` | Помилка контрольної суми кадру (BCC). |
| **-100003** | `ERR_END_OF_DATA` | Кінець даних (більше немає даних для передачі). |
| **-100004** | `ERR_NOTFOUND` | Елемент / запис не знайдено. |
| **-100005** | `ERR_NO_RECORDS` | У базі даних немає жодного запису. |
| **-100006** | `ERR_ABORTED` | Операцію перервано або скасовано. |
| **-100007** | `ERR_WRONG_MODE` | Неправильний режим роботи (наприклад, апарат знаходиться в режимі навчання). |
| **-100008** | `ERR_NOT_READY` | Пристрій не готовий до виконання команди. |
| **-100009** | `ERR_NOTHING_TO_PRINT`| Немає даних для друку. |

## 2. Фіскальна пам'ять (ФП) (-100100 .. -100116)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-100100** | `ERR_FM_BUSY` | Фіскальна пам'ять зайнята іншим процесом. |
| **-100101** | `ERR_FM_FAILURE` | Апаратний збій ФП (неможливо прочитати або записати блок). |
| **-100102** | `ERR_FM_WRITE_PROTECTED` | Запис у ФП заблоковано апаратним захистом. |
| **-100103** | `ERR_FM_WRONG_ADDRESS` | Невірна адреса пам'яті. |
| **-100104** | `ERR_FM_WRONG_SIZE` | Невірний розмір блоку. |
| **-100105** | `ERR_FM_NOT_CONNECTED` | Модуль фіскальної пам'яті фізично не підключено. |
| **-100106** | `ERR_FM_WRONG_CHECK_SUM` | Збій контрольної суми блоку у ФП (пошкодження записів). |
| **-100107** | `ERR_FM_BLOCK_IS_EMPTY` | Запитуваний блок порожній. |
| **-100114** | `ERR_FM_FULL` | **Фіскальна пам'ять повністю заповнена** (потрібна заміна блоку ФП). |
| **-100116** | `ERR_FM_BLOCKED` | **Фіскальна пам'ять заблокована**. |

## 3. Чекодрукний механізм (Printer Driver Errors) (-100400 .. -100414)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-100400** | `ERR_LTP_VCCERR` | Помилка живлення принтера (3.3V). |
| **-100401** | `ERR_LTP_SVPERR` | Помилка високої напруги живлення голівки (24V або 8V). |
| **-100402** | `ERR_LTP_STHERR` | **Перегрів термоголівки** (температура перевищує допустимий ліміт). |
| **-100403** | `ERR_LTP_PESENS` | **Закінчився папір** (Paper End Sensor). |
| **-100404** | `ERR_LTP_HDSENS` | **Кришка принтера відкрита** (Cover Open Sensor). |
| **-100405** | `ERR_LTP_NESENS` | Папір закінчується (Near Paper End Sensor). |
| **-100407** | `ERR_LTP_CUTERR` | **Заклинювання ножа** (Cutter Error) — ніж не зміг повернутись у вихідне положення. |
| **-100414** | `ERR_LTP_MOTOR_OVERRUN` | Перевантаження крокового двигуна протяжки паперу. |

## 4. Системні помилки (-100500 .. -100511)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-100501** | `ERR_SRAM_ERROR` | Помилка оперативної пам'яті (RAM Error). |
| **-100502** | `ERR_FLASH_ERROR` | Помилка Flash-пам'яті мікроконтролера. |
| **-100503** | `ERR_SDCARD_ERROR` | Помилка карти microSD (носія КСЕФ). |
| **-100506** | `ERR_NO_RAM_BATTERY` | **Розряджена батарейка живлення годинника/RAM** (потрібна заміна CR2032). |
| **-100507** | `ERR_SAM_ERROR` | Помилка модуля безпеки (SAM крипточіпа). |
| **-100508** | `ERR_RTC_ERROR` | Збій годинника реального часу. |

## 5. Помилки режиму реєстрації продажу (Registration Mode) (-111000 .. -111098)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-111002** | `ERR_R_SYNTAX` | Синтаксична помилка в команді продажу (невірні параметри). |
| **-111003** | `ERR_R_NPOSSIBLE` | Неможливо виконати операцію в поточному стані. |
| **-111004** | `ERR_R_PLU_NOTEXIST` | Товар з таким PLU-кодом не знайдено в базі каси. |
| **-111005** | `ERR_R_PLU_VAT_DISABLE` | Заборонена ставка ПДВ або податкова група не активована. |
| **-111006** | `ERR_R_PLU_QTY_PRC` | Переповнення при множенні кількості на ціну (`Qty * Price` завелике). |
| **-111007** | `ERR_R_PLU_NO_PRC` | Товар не має запрограмованої ціни. |
| **-111013** | `ERR_R_ECR_OVR` | Переповнення денних фіскальних регістрів. |
| **-111015** | `ERR_R_OPEN_BON` | **Чек уже відкрито** (не можна відкрити ще один чек, не закривши поточний). |
| **-111016** | `ERR_R_CLOSED_BON` | **Чек закрито** (спроба додати позицію або оплату в закритий чек). |
| **-111017** | `ERR_R_PAY_NOCASH` | Недостатньо готівки в касі для операції видачі/решти. |
| **-111019** | `ERR_R_OVF_TRZ_BUFF` | Переповнення буфера чека (досягнуто максимальну кількість рядків). |
| **-111024** | `ERR_R_END_OF_24_HOUR_PERIOD` | **Блокування 24 години!** Минуло більше 24 годин з першого чека в зміні, необхідно зняти Z-звіт! |
| **-111047** | `ERR_R_OPEN_FISCALBON` | Фіскальний чек відкрито (заборонені нефіскальні операції). |
| **-111048** | `ERR_R_BUYERS_TIN_IS_ENTERED` | ІПН покупця вже введено в чек. |
| **-111063** | `ERR_R_AMOUNT_BIGGER_BILLAMOUNT`| Внесена безготівкова сума перевищує залишок до сплати. |
| **-111064** | `ERR_R_AMOUNT_SMALLER_BILLAMOUNT`| Спроба закрити чек, коли сума оплат менша за суму підсумку. |
| **-111065** | `ERR_R_ZERO_BILLAMOUNT` | Сума чека дорівнює нулю (порожній чек не можна фіскалізувати). |
| **-111072** | `ERR_R_MORE_THAN_ONE_VAT` | У чеку заборонено змішувати несумісні податкові групи. |
| **-111077** | `ERR_R_WRONG_DATE_FM` | Дата чека раніша за дату останнього запису у фіскальній пам'яті! |
| **-111095** | `ERR_R_NOT_EXCISE_PLU_WITH_EXCISE_STAMP` | Товар не позначений як підакцизний, але передано марку. |
| **-111096** | `ERR_R_EXCISE_PLU_WITHOUT_EXCISE_STAMP` | **Підакцизний товар без акцизної марки!** Законодавство вимагає введення марки. |
| **-111097** | `ERR_R_EXCISE_PLU_FORBIDDEN` | Акцизна марка не пройшла валідацію або заборонена. |
| **-111098** | `ERR_R_WAIT_UNTIL_MIDNIGHT` | Неможливо відкрити нову зміну з цією датою (чекайте опівночі). |

## 6. Електронний журнал КСЕФ (Electronic Journal / KLEN) (-105000 .. -105019)

| Код | Символічна назва | Опис помилки |
| :---: | :--- | :--- |
| **-105000** | `ERR_EJ_NO_RECORDS` | У КСЕФ немає записів. |
| **-105002** | `ERR_EJ_WRONG_MAC_RECORD` | Збій криптографічного підпису чека модулем безпеки (SAM). |
| **-105007** | `ERR_EJ_ALREADY_SIGNED` | Документ уже підписано цифровим підписом. |
| **-105009** | `ERR_EJ_NEAR_FULL` | Карта пам'яті КСЕФ майже заповнена. |
| **-105010** | `ERR_EJ_FULL` | **Карта пам'яті КСЕФ заповнена** (потрібна заміна носія). |
| **-105016** | `ERR_EJ_CANNOT_OPEN` | Неможливо відкрити файл КСЕФ на microSD. |
