# 🖨️ Datecs / Exellio Fiscal Printer Simulator (Протокол v2.11)

Програмний емулятор фіскальних реєстраторів лінійки **Datecs / Exellio** (DP-25X, DP-05C, WP-50X, FP-700X, FMP-350X тощо) на основі офіційної специфікації:
📄 `PM_CommunicationProtocol_v2.11_eng.pdf`

---

## ⚡ Швидкий старт

### 1. Запуск симулятора
У корені проекту виконайте:
```bash
./run_simulator.sh
```
або вручну:
```bash
cd datecs-simulator
python3 datecs_simulator_main.py --port 4999 --web-port 8088
```

### 2. Запуск тестового клієнта
У сусідньому терміналі:
```bash
python3 datecs-simulator/datecs_test_client.py
```
або через віртуальний COM-порт:
```bash
python3 datecs-simulator/datecs_test_client.py --serial datecs-simulator/kasa_serial_port
```

## 🌐 Інтерфейси підключення

### 1. Мережевий сокет TCP/IP (LAN / Wi-Fi)
* **Хост:** `127.0.0.1` (або IP вашого комп'ютера в локальній мережі)
* **Порт:** `4999` (стандартний порт `LANport_fpCommands` протоколу Datecs)
* **Для Android емулятора:** використовуйте IP `10.0.2.2:4999` або виконайте прокидання порту через adb:
  ```bash
  adb forward tcp:4999 tcp:4999
  ```

### 2. Віртуальний послідовний порт (Virtual Serial PTY / COM-порт)
* **Символьне посилання:** `./datecs-simulator/kasa_serial_port` (Unix PTY slave, наприклад `/dev/ttys016`)
* Будь-яка програма (Kotlin драйвер, Python скрипт, емулятор Bluetooth SPP), налаштована на цей шлях, взаємодіє з симулятором як зі справжнім апаратним портом RS-232 / Bluetooth.

### 3. Інтерактивний Веб-дашборд
* **URL:** [http://localhost:8088](http://localhost:8088)
* **Можливості:**
  * Візуалізація чекової стрічки в реальному часі (Thermal Paper Roll)
  * Дворядковий VFD-дисплей покупця (зелений люмінесцентний екран)
  * Відображення готівки в сейфі, лічильника Z-звітів, номерів чеків
  * Кнопки швидкого тестування (створення тестового чека, X-звіт, Z-звіт, внесення грошей, імітація закінчення паперу чи відкриття кришки)

## 🛠️ Архітектура симулятора (Modular Triad)

1. `datecs_contract.py` — типи даних, константи байтів протоколу (`PRE`, `PST`, `EOT`, `SEP`), коди помилок та команд, бітові маски статусів.
2. `datecs_framer_logic.py` — бінарний парсер/фреймер, кодування Datecs Nibbles (`nibble + 0x30`), розрахунок та верифікація контрольної суми BCC.
3. `datecs_engine_logic.py` — ядро фіскальної логіки: накопичувальні регістри зміни, розрахунок знижок, ПДВ, залишку готівки, база артикулів PLU.
4. `datecs_dispatcher_logic.py` — диспетчеризація команд, розбір параметрів через `\t`, формування типізованих відповідей.
5. `datecs_tape_logic.py` — візуалізатор паперової стрічки чека та емулятор дисплея покупця.
6. `datecs_socket_transport.py` — асинхронний TCP-сервер (порт 4999).
7. `datecs_serial_transport.py` — віртуальний послідовний COM-порт на базі Unix PTY.
8. `datecs_web_transport.py` — вбудований Web-сервер з панеллю моніторингу та REST API.
