# 🇺🇦 KasaApp v5 — Мультиплатформова екосистема фіскального робочого місця касира (POS)

> **AI-Native, Android-First & Desktop Multiplatform POS Terminal for Datecs/Exellio RRO**  
> Побудовано за стандартами суворої типізації, модульної тріади (`contract`, `logic`, `transport`) та ліміту 80–250 рядків на файл (оптимізація під Flash-моделі).

---

## 🏛 Модульна архітектура проекту

```
kasaApp-v5/
├── core-model/          # Доменна онтологія: FiscalMath (ПДВ 20/7%, Акциз 5%, заокруглення НБУ №25), Receipt, Product
├── core-protocol/       # Чисте Kotlin-ядро Datecs/Exellio: SOH/ETX дефрагментатор, BCC, 6 статусних байтів, ваги, FSM
├── feature-pos/         # Двопанельний POS-екран касира (Compose Multiplatform) + MVI машина станів PosViewModel
├── feature-sync/        # REST API клієнт до FastAPI (Ktor 3, JWT RS256, FileJsonSyncStorage дискова черга)
├── feature-transport/   # Апаратні адаптери зв'язку (Serial COM jSerialComm, Bluetooth Classic SPP, ваги)
├── desktopApp/          # Запускний Desktop-додаток касира (macOS, Windows, Linux)
└── androidApp/          # Запускний Android-додаток (Bluetooth Classic RFCOMM SPP, Edge-to-Edge)
```

## 🚀 Швидкий старт та запуск

### 1. Вимоги до оточення
- **JDK:** OpenJDK 17 (Adoptium Temurin 17 або сумісна)
- **Операційна система:** macOS (Apple Silicon / Intel), Linux або Windows

### 2. Запуск юніт-тестів усіх модулів:
```bash
./gradlew test
```
*Усі 30+ юніт-тестів виконуються менш ніж за 1 секунду завдяки чистій JVM-ізоляції.*

### 3. Запуск робочого місця касира на ПК / Mac:
```bash
./gradlew :desktopApp:run
```

## 🔌 Підключення торгового обладнання

### А. Фіскальні реєстратори (РРО Exellio / Datecs)
- **Протокол:** Datecs Protocol (SOH `0x01` .. ETX `0x03`, Nibble-кодовані довжина та контрольна сума BCC).
- **Підключення на ПК / Mac:**
  - Через USB-кабель (віртуальний COM-порт `/dev/cu.usbserial...` або `COMx`).
  - Через Bluetooth SPP (на Mac автоматично створює `/dev/cu.DP05...`).
  - Клас драйвера: `SerialKasaTransport` з автоматичним скануванням `listAvailablePorts()`.
- **Підключення на Android:**
  - Bluetooth Classic SPP (UUID `00001101-0000-1000-8000-00805F9B34FB`).
  - Клас драйвера: `BluetoothKasaTransport`.
- **Автономне тестування без обладнання:**
  - Клас `SimulatedKasaTransport` симулює 100% поведінки реального РРО, включаючи помилки паперу, обрив зв'язку, зміну > 24 год та аварійні відкати чеків (Void).

### Б. Електронні торгові ваги
- **Сумісні моделі:** CAS, DIGI, Промприлад, ВТА-60 (протокол `ST,GS,+  1.250kg\r\n`).
- **Можливості:**
  - Безперервний стрім показань маси у віджет касира (`ScaleStreamTransport`).
  - Індикатор стабільності ваги (`● СТАБІЛЬНО` / `○ РУХ`).
  - Апаратне тарування кнопкою `"Тара"` (команда `"T\r\n"`).

### В. Сканери штрих-кодів
- **Режими:** USB / Bluetooth HID (Keyboard Wedge) або ручне введення.
- **Логіка:** Автоматичний інкремент кількості для штучного товару при повторному скануванні, авто-взяття поточної стабільної ваги з ваг, виклик діалогу введення акцизної марки для алкоголю/тютюну.

## 🌐 Синхронізація з FastAPI бекендом

- **Локальний бекенд:** `repos/FastApi/`
- **Запуск бекенду:**
  ```bash
  cd repos/FastApi
  uvicorn app.main:app --reload --port 8000
  ```
- **Маршрути:**
  - `POST /jwt/login/` — вхід касира та отримання JWT RS256 Bearer токена.
  - `GET /products/` — довідник товарів із фільтрацією за магазином та касою.
  - `POST /orders/` — збереження чека продажу з позиціями та акцизними марками.
- **Офлайн-стійкість:**
  - Якщо інтернет відсутній, чеки зберігаються в локальний JSON-файл `~/.kasaapp/offline_orders.json` через `FileJsonSyncStorage`.
  - При появі зв'язку або натисканні кнопки `"Синхронізація"` черга транзакційно вивантажується на сервер.

## ⚖️ Фіскальна математика (FiscalMath)
Усі грошові розрахунки ведуться **виключно в цілих копійках (`Long`)**:
1. **ПДВ 20% (Група А):** `round((Сума * 20) / 120)`
2. **ПДВ 7% (Група В, ліки):** `round((Сума * 7) / 107)`
3. **Роздрібний акциз 5% (алкоголь, тютюн):** `round((Сума * 5) / 105)`
4. **Заокруглення готівкового розрахунку (Постанова НБУ №25):**
   - 1..4 коп $\rightarrow$ 0 коп
   - 5..9 коп $\rightarrow$ 10 коп
   - При безготівковій оплаті карткою сума списується копійка в копійку без заокруглення.
